Entry for [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) on make.fun.

`main.py` writes a single cat joke, one line, to `/output/entry.txt`. The joke:

> My cat pushed my glass off the table, watched it shatter, then glared at me like I was the clumsy one.

Run it with `python3 main.py`. It needs nothing but the standard library.
